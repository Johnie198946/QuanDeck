# 后台更新期间保留附件阅读状态

后台任务回执或项目快照更新时，同一源执行、同一 Markdown 附件链接的预览必须保持打开，保留 HTML iframe 和当前阅读位置，不重复读取附件。切换为不同附件路径或不同源执行时重置旧预览，避免沿用错误内容或访问范围。

实现保持 ReactMarkdown 的链接、图片、段落及表格组件类型稳定；组件映射只在源执行标识改变时更新，附件以源执行和路径共同标识。附件服务、读取权限和 HTML 隔离策略保持原有行为。

隔离浏览器验证：连续 13 次快照刷新后对话框和 iframe DOM 身份不变、滚动位置不变、同一附件只读取一次；文件与源执行切换后旧预览关闭；390/1440 宽度、Escape 关闭和焦点返回正常。测试使用生产组件和隔离主机桩，不调用源 Agent 或真实用户数据。
