# QuanDeck V0.10：在方案中看见、比较、调整

更新：2026-11-17。验收结果以 completion manifest 和 Release 回执为准。

## 产品方向

讨论不应像填写一张确认表。用户先看到一句判断与最有用的视觉证据，再对具体内容表达意见。方案阶段只决定方向、交付形式和执行逻辑；具体核查、制作和汇总仍进入已确认的任务树。

## 方案画布

- 一句结论下方呈现真实照片、路线、选项对比或事实卡；不强迫每次回复都使用所有类型。
- 照片保留来源、说明和放大入口。支持 HTTPS 图片和当前任务已登记的图片附件；本地路径不能由渲染器任意读取。
- 路线先显示目的与来源，Google 地图显式加载；只允许官方嵌入地址，不伪造查询结果。
- 对比卡让用户选择“偏好这项”“不选这项”或填写调整意见。输入绑定当前卡片或选项；用户无需重复描述是哪一张图。
- 一次卡片偏好不是整份方案确认，不创建任务、不启动执行。整份方向确认继续使用独立版本化命令。
- 宽屏让卡片并排；窄屏回流。图片放大支持 Escape 退出和焦点返回，减少动态效果偏好生效。

## 台帐与后端

`visualBlocks` 是 Agent 公开结论的一部分；规范化后固定 id、内容摘要、来源、消息与结论关联，写入项目台帐的视觉回执。方案视图和会话视图消费相同的持久化结论。后台不从任意聊天文本推断视觉事实。

卡片反馈绑定 projectId、taskId、planId、conclusionId、sourceMessageId、draftVersion、blockId、blockHash、optionId 和 feedbackId。先保存用户反馈，再向对应源会话发送。跨项目、过期方案、不同源消息、错误块或选项拒绝发送。同一反馈标识不能修改含义，重复操作不能重复写入。

发送意图先持久化为 sending；源端确认后立刻记录 sent，再刷新视图。发出前失败可以重试；已经发出但受理不明保留 unknown，显示回源核对，禁止盲重发。确认成功不会因后续刷新失败倒退。用户偏好是讨论事实，不作为整份方案授权或强制约束。新的讨论上下文包含已保存反馈。

台帐仍是唯一可写事实来源；黑板、树、进度与视觉交互都是投影，不建立单独的聊天项目状态。

## 时间轮盘

计划来自真实日程，实际来自带时区的执行区间。轮盘的时针跟随当前时钟，计时事实跟随源端回执，暂停不延长执行。支持前后日期、回到今天和最近有执行的日期，日程详情保留所选日期。未排计划的执行也有明细，不能在总数中出现但在列表中消失。零数据明确解释当前日期范围，不用昨日数据填充今日。

## 项目与任务树

项目标签使用项目—主任务—子任务层级，任务标签聚焦当前项目。展开箭头仅展开，标题打开简洁详情，再明确进入任务或成果。展开其他项目不会改变当前操作项目。任务节点使用项目、主任务和子任务组合标识。

搜索命中子节点时保留祖先路径。筛选只控制显示，不改变完成进度分母。已完成、待处理和真实源步骤可直接扫读；源端没有总步骤时不制造百分比。默认只展开当前相关层级，宽屏就地详情、窄屏弹窗，支持键盘与回焦。

任务行、执行侧栏、会话入口与最新回复使用同一执行来源。有活动子任务时，展示子任务名称与真实状态，父任务的旧暂停会话留在历史详情；多个子任务分别展示，摘要标明来源。任务补充只发往明确可续谈的当前执行，等待授权时不退回旧父会话。

## 轻量输入与附件

任务默认只有一行补充入口。点击、粘贴图片或拖入文件即展开；正文与附件可一次保存，也可在源会话允许续谈时一次发送。图片缩略图、其他文件标签和历史条数取代常驻大文本框。

支持多格式文件与批量添加，也支持纯附件输入。草稿通过独立输入标识持久化；迟到的保存或发送回执不能清掉更新后的草稿。错误保留文字、附件和明确状态。

后端原子保存输入与附件关联，按输入标识校验幂等。续谈前核对附件属于当前任务，将文件实际导出到 Agent 项目目录，再把验证后的真实路径写入提示。拷贝失败不发送只有文字的替代消息。相同输入成功后不重发，受理不明先回源核对。

## 验收

- 320 / 768 / 1024 / 1440 / 1920 像素布局与键盘交互。
- 图片来源、加载失败、附件来源绑定、地图显式加载与官方域名限制。
- 反馈保存、重试、刷新、旧版本隔离、跨项目隔离与受理不明保护。
- 跨日时区、暂停、最近执行与未排计划明细。
- 树层级、搜索祖先、筛选分母与正确项目的详情入口。
- 粘贴图片、多文件上传、纯附件保存、实际导出、重复提交及草稿竞态。
- 继续保留 V0.9 的方向确认、任务分解、子任务验收后汇总与沉浸成果阅读。

发布目标：Apple Silicon Mac、Windows x64。构建、标签、安装包、哈希与原生安装检查必须来自同一提交。
