# 在帮你想里整理、复用方法

## 从资料到工作流

在「灵感逻辑」里新建一张画布，点左侧的「导入方法」，选择笔记、文件或公开网页。一次可以选多份。先展示每份资料的识别结果，再把勾选的结果加到当前画布。每份资料独立判断，多个来源之间的关系由用户连线。

| 原文提供的内容 | 预览与落图 |
| --- | --- |
| 目标、起始输入、可衔接的步骤、最终产物和检查标准 | 标记为工作流。从输入排到输出，保留有依据的分支或汇合。每一步映射为检索、规划、筛选、预订、检查、整理或自定义步骤。 |
| 有具体想法或经验，缺少可复用的步骤 | 标记为参考。提炼有原文依据的灵感卡，显示缺少什么，留给使用者决定如何连接。 |
| 无法读取的网页或文件，或无可靠的原文依据 | 显示该来源的读取或核对结果。其他有效来源仍可选择。 |

例如，原文写“根据出行日期和预算搜票，得到候选车次；再比较候选车次，生成行程表，核对每项票价不超预算”。第一张卡做资料检索，第二张卡做比较筛选，连线交付“候选车次”。点第二张卡，可以核对它用什么、产出什么、怎么算通过，以及这些内容出自哪一句。原文给出订票或攻略网址时，可从相应步骤打开。单独一句“清晨在鸭川散步很舒服”则适合做参考卡。

**分工**：Agent 阅读并判断资料的用途，给出步骤、依赖和逐字引文。QuanDeck 核对出处、输入输出与标准是否出现于原文，并检查连线端点、方向、重复、断开与循环。无法形成可核实流程时，保留有依据的参考。用户确认后落图，可以重排、编辑、连线或删除；保存的方法用来指导后续任务，实际执行交给「帮你管」中选定的 Agent。

## 多次复用同一套做法

完成编辑后点「存为模板」，为它命名。方法总结可自己写，也可点「让 AI 写总结」再调整。下次从「方法模板库」用模板新建一张画布，改动只作用于这份副本。删除画布或模板时，仍被其他画布或笔记使用的附件会保留。

在「帮你记」点纸飞机，可用模板名称或步骤内容找到这套方法，一起交给项目任务。问 AI “我有哪些方法模板”，也能从结果返回模板库。

## 看笔记之间的联系

「知识图谱」中一个星球代表一篇笔记，线表示有依据的关系，独立笔记也会显示。拖动星球能看到邻居随之移动，松手后逐渐复位。点击星球看笔记，点击连线看关系及原文依据，点空白或按 Esc 收起说明。支持搜索、缩放、列表和系统的减少动态效果设置。
