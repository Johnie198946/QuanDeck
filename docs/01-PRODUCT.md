# QuanDeck 产品定义
目标：管理个人工作、生活、知识与 Codex 等执行者，而非成为 Agent Runtime。用户记录、校准、决策、分派、验收；AI 主动理解、研究、发现关联和错误、跟踪、建议；执行者完成任务。

固定导航：首页、帮你记、帮你想、帮你管、帮你盯、帮你找；设置在左下。禁止增加帮你做。首页聚焦当前最重要事项；记负责记录；想负责知识关联；管负责项目任务；盯负责进度异常；找负责全局检索。共享数据，不重复存储。项目可以独立创建，不强制来自灵感。随口意向不是正式任务。

Less is More：入口、步骤、学习成本最少。ELI5：做了什么一句话，重要发现一句话，必要操作直接给按钮；无价值不打扰，不展示后台过程。AI 保持独立判断，不迎合，不编造进度、来源、结论。用户拥有决策权。保留历史与原文。
