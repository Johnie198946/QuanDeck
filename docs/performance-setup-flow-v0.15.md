# V0.15 性能、应用级 Agent 配置与程序流程图

## 用户体验与后端边界

本次处理真实使用中的卡顿、重复配置和方向页难以看清执行结构三个问题。任务、来源、规范与成果仍使用既有台帐；黑板和流程图均为投影，不增加另一套任务状态。

### 1. 增量读取与持久化

- 前端首次读取项目全量；后续携带后端生成的读取游标，仅接收变化项目及完整项目 ID 列表。删除项目从列表移除，应用重启或恢复备份产生新游标命名空间，不能误用旧缓存。
- 游标不是业务版本或授权。项目实际提交对象变化即产生新游标，因此同版本配置变化也可到达前端。读取返回隔离副本，不允许通过缓存修改台帐。
- 连续刷新合并为一个在途请求及必要的追赶读取；未变化项目保留引用，不重复触发工作台和托盘派生。切换数据源、卸载组件及初始读取晚于推送时，不应用旧响应。
- 仓库只克隆实际变化项目；跨项目来源核对保留隔离和原有失效语义。存储跳过同值写入及已核对且未变化的不可变事实；外部句柄版本栅栏、SQLite 原子事务、不可变历史拒绝改写与回滚仍生效。
- 历史数据不删减，进展事件不丢弃，不用延迟状态更新制造流畅假象。
- 启动恢复只回放持久化游标之后的新事件；仅在同一 run 和源会话身份匹配时跳过已入账前缀。停止证明未改变不再写回，历史事件之后仍以驱动最终停止/暂停事实校正。后台台帐导出逐项让出事件循环，首屏不再等待历史导出队列排空。

### 2. Agent 配置一次，项目只选文件目录

应用保存 Agent 身份、工具、程序路径、模型及程序参数；不保存共享项目目录，不复制源工具的凭据或授权决定。各项目分别保存目录和独立运行连接，源会话继续归属单个任务。

新建项目填写名称并选择文件目录。后端检查目录，再用应用默认配置进行轻量协议握手并建立项目绑定，不发送模型业务请求、不创建聊天或任务。没有配置过 Agent 时仍可建立项目，后续应用配置完成后补齐连接。

升级时，已有配置参数一致则复用；存在不同模型或参数时保留旧项目覆盖，要求明确选择应用默认值，不能随意挑选。旧项目目录、运行和会话保持原归属。连接失败仍保留新项目与目录并说明原因，重试补齐同一个项目的缺失绑定。

既有项目连接不随应用配置自动改变。项目设置中的“修复此项目的 Agent 连接”让用户指定一项，后端以同一目录重新验证应用默认配置，再用 expectedConnectionId 做并发核对后替换。活动会话、配置变化、并发改绑或验证失败时保留原连接，不派发任务。

“一次配置”表示持久保存并跨项目复用，不代表源端账号永不过期或永久取消执行权限。更换程序、模型或源登录失效时仍需修正对应配置。讨论优先使用当前项目绑定，应用配置测试连接不能成为任务工作目录。

### 3. AI 提供结构，程序绘图

方向页在正文前固定显示“已登记任务流程”，直接来自当前台帐中的任务、依赖与子任务汇总。节点展示实际状态，可点击定位任务；缺少依赖不会自行猜测串行顺序。图形是台帐投影，不能反向授权执行。

AI 可在现有讨论视觉块中提交 `flow` v1：节点 ID、类型、标题、说明与边的来源、目标、标签。后端严格检查字段、唯一 ID、引用、数量与文本长度，再确定性计算布局。React 只绘制受控 SVG 元素，不执行 AI 提供的 HTML、SVG、脚本、样式或任意 Mermaid。

支持分支、汇合及返回关系；回路只表达讨论中的逻辑，不创建可执行依赖环。上限 40 节点、80 条边；大项目进入局部任务阅读。无效图明确显示问题并保留原始回复，不静默丢弃正文。已有长段散文不自动猜成正式任务图。

前端保留正文、流程图与文字关系视图。窄屏图在独立区域平移，支持放大阅读、Esc 关闭、焦点恢复和键盘节点定位。状态同时有文字说明；无远程绘图服务或图表请求。

## 验证方法与证据

真实库只读副本约 11.6 MB，7 个项目。原始业务数据仅留本机，不入 Git 或 Figma。

- 后端测量与存储防回归：见 [公开验证说明](release-verification.md)。
- 真实库恢复链原本重放 2,311 条已入账事件，造成全库重复克隆和相同状态写回。同一只读副本、隔离自动推进及摘要后的恢复测试：79,383.7 ms → 71.0 ms，克隆 16,560 → 13 次，项目列表读取 2,312 → 1 次，持久化 97 → 1 次。见 [公开验证说明](release-verification.md)。此数字只表示恢复链，不表示完整应用启动时间。
- 前端传输准备对比：同一副本、15 轮克隆与 JSON 编解码；全量 11,566,414 字节，中位 66.972 ms；无变化增量 990 字节，中位 0.004 ms；当前项目变化增量 1,191,841 字节，中位 6.274 ms。
- 以上是明确操作的微基准，不是点击到绘制的端到端延迟；进程 CPU 峰值和 CUA 工具耗时不能冒充 UI 响应时间。
- 配置覆盖无项目首次设置、同值旧配置迁移、冲突选择、目录校验、失败后保留项目及重试、项目与应用绑定隔离。
- 原生配置验收：保存应用默认 Codex 后，新项目只填名称及文件目录即可自动建立 Codex/Hermes 独立连接，任务数为 0、执行数为 0，无需再次配置或打开聊天。
- 流程图覆盖结构拒绝、中文长标题、分支/汇合/回路、320/768/1024/1440 布局、放大/关闭/键盘/等价文字视图。

最终构建、真实安装、配置复用与当前台帐流程图的实际验证结果记录在本任务 completion manifest。不得仅以微基准宣称所有规模和所有页面的卡顿都消失。
