# 帮你想：从一个想法到一次行动

## 发现笔记之间的联系

打开「帮你想」的知识图谱，选一篇笔记，再点它的连线。右侧会告诉你两端说了什么、为什么可能有关、这个发现可以怎样用，以及什么情况下不适用。点原文可以回去核对。只有一篇笔记也可以发现其中前后矛盾的说法。

例如，你在一篇笔记里写了“服务排队太长就切换端点”，在另一篇写了“景点等待超过 20 分钟，就换下一个”。Agent 可以提出一个值得试的办法：把路线也做成能临时切换的两条路。你可以核对两段原文，再用过去一天的排队时间试算，看这招能否省时间。

### 连线从哪里来

1. **拆出具体想法。** QuanDeck 把保存的笔记分段交给设置中已连接的 Agent。Agent 提取事实陈述、观点、方法、经验等，每条必须带能在原文中定位的引文。公开来源的引文和 Agent 以前写的答案会标明出处。
2. **找对照对象。** QuanDeck 从全库查找用词相近、目标或做法相近、已经间接相连的想法，还会轮换尝试原本没有联系的旧材料。Agent 对照具体证据判断是否同源、补充、矛盾，或能否复用、组合出新做法。只有相同词语、说不清实际用途的建议会被过滤。
3. **由你判断。** 每条推断可以保留或忽略。出现冲突时，你能看到双方各自的条件，再决定是否确认。忽略后的同一组证据会记住你的选择。
4. **跟上笔记变化。** 桌面应用运行且 Agent 可用时，保存后自动检查改动，复用已读过的段落。如果在分析时编辑笔记，同次打开应用期间会接着已核对的部分做，只重查变动涉及的内容。每周轮换回看旧想法。断线或原文在分析期间变化时，已有结果仍可查看，稍后会重试。文件能读到哪些内容与格式、系统有关，附件详情会注明部分读取或无法读取。

## 把自己的做事步骤排出来

在「灵感逻辑」选择笔记并点「灵感提炼」，勾选想留下的观点。每条选中的想法成为一张卡，同一篇笔记可以提供好几张卡。少了一步，点「新建灵感」补上；网页、截图或文件也可以粘贴或拖到画布当参考。

拖动卡片摆好位置，从一张卡的输出点连到下一张的输入点。也可以依次点两个接点。选中连线，在右侧填上关系和说明。例如「京都玩法 → 前往 → 大阪玩法」可以写“离开京都后去大阪，晚上在难波吃饭”。反转连线时，可以给回程单独写说明。

1. 想核对一次提炼，可以从卡片回到出处。来源改过后，以核对到的版本为准。
2. 移除画布上的某一步，原笔记仍可在「帮你记」打开。
3. 回到「帮你记」，选中要做的事，点纸飞机。在「执行思路」输入记得的几个字，选已有思路，也可以写一句临时要求，按回车变成标签。
4. 选项目或新建项目后发送。Agent 会收到选中的需求、相关笔记上下文、思路的步骤和连线，以及你补充的要求。结果可以从原笔记的回执或「帮你管」的任务中打开。
