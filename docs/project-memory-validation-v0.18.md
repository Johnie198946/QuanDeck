# V0.18 项目记忆验证

本版验证使用隔离合成数据，没有向真实项目添加测试日志，也没有发送真实业务数据到模型。

## 已核对的行为

- 项目、任务要求和规范完整进入必需输入；仅相关前置成果及交接随任务发送。无关任务增加不增加任务资料包正文。
- 原始项目要求超过 6,000 估算 token 时可为必需材料有界扩展；尾部条件完整。超过硬上限或最终协议总预算时不调用执行端，不留下新 claim/session。
- AI 项目摘要最多 20 项任务，完整请求最多 6,000 估算 token；旧排队输入也执行白名单。结果不能引用未发送的任务或事实。
- 经验必须有当前有效的验收来源；候选、确认、版本冲突、相同提交重试、撤回、跨项目拒绝、来源失效和中文相关性均有领域检查。
- 默认记忆与导出不含执行流水、回执或用量。隔离噪声仅用于证明该边界，不写入真实项目。
- 分页游标绑定业务内容；心跳不打断翻页，要求或完整来源变化会拒绝旧游标。投影内容相同时不重复生成文件，历史只保留当前与前一份派生版本；原始业务事实不清除。
- 隔离浏览器创建项目，检查简报、任务原文、完整条件、候选经验、确认、重启保留、来源变更和撤回。320、768、1024、1440 宽度无横向溢出，Escape 返回原入口焦点，无页面异常。保存经验不会提交外层项目设置表单。

## 证据范围

完整应用回归包含既有方向、任务拆解、父子任务、交付契约、验收、自动合并和发布来源检查；本版不修改它们的业务语义。桌面安装验证使用临时用户目录，检查空库首启、协作落盘、生成记忆文件及既有交付链。

测试操作者和确定性夹具完成业务核对。本轮没有新增真实外部 Agent 推理验证；不能据此声称模型必然理解所有资料，或所有用户项目的性能都达到相同数值。估算 token 不是模型真实计数。语义冲突识别、个人经验库和自动分段读取不属于本版已交付能力。

最终提交、双平台安装检查与包哈希以 V0.18.0 Release 的匿名 verification.json 为准；源码验证、安装验证和本机更新分别记录。
