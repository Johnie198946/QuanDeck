# 账户检查与源鉴权的边界

账户信息检查是可选能力。查询方法缺失、账户元数据暂时不可用时，登录项显示“未知”，允许源 Agent 在真实任务受理时完成鉴权；这不代表已经登录、模型可用或有剩余额度。

明确的认证失败仍阻止派发，包括无账户且源要求登录、HTTP 401/403、未认证、访问或刷新令牌已过期，以及源提供的明确认证错误码。JSON-RPC 错误跨进程传递时，除脱敏消息外只保留合法数字状态和白名单认证错误码，不保存任意 data、请求头或凭据。HTTP 状态字段优先于 RPC 的通用 code。

不能单凭出现 authentication 或 token 就推断登录失效。账户元数据暂不可用、token 用量读取失败、分页 token 失效保持原来的未知状态；本机 EACCES 仍为目录权限问题。

验证覆盖：可选检查失败后由模拟源接收任务；结构化 401/403 和明确未登录在发送任务消息前被拒绝；RPC 传递保留分类证据且不保留敏感负载。未发起真实模型调用。
