# 成果地图中的人工验收

项目、任务和子任务共用成果地图。选中候选正文后，可展开「核对这份成果」，查看该成果所属任务当前版本的验收条件，逐项勾选并记录核对说明，再确认认可或要求修改。默认不勾选条件；认可要求全部通过，退回必须说明需要修改的内容。

入口按 artifact.key 解析真实任务和子任务，提交既有 collaborate(review) 命令：固定当前 submissionId、task spec revision 对应条件、expectedVersion 和幂等键。它不会认可父任务、其他任务或其他候选。相同 artifact 覆盖的多个输出槽会一起反映这次验收；不同 artifact 保持独立。

旧版候选、要求变更、归档或非待验收状态不允许提交。失效来源不能认可，可以对仍属当前待验收候选要求修改。后端保留子任务、依赖、交付完整性和版本校验；界面直接展示拒绝原因。验收后已认可成果不重复提供按钮，历史正文和记录继续保留。

验证：真实领域命令构建的独立夹具覆盖子任务作用域、显式条件/说明、失效来源、旧submission与版本拒绝、幂等与退回。隔离浏览器完成认可和退回，并检查320/768/1440/1920宽度，无页面错误。未调用源Agent或读取真实项目。
