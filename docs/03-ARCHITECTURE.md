# 底层设计（逻辑模型，非已验证物理 schema）
统一知识库无独立管理页。笔记、附件、外部资料、研究、成果、决策与经验自动索引，保留原文和出处，不复制原文。三层：原始信息、知识理解、知识关联。六类逻辑对象：Source（原始引用）、Knowledge（事实/观点/经验/推断）、Entity（对象）、Relation（关系与证据）、Insight（发现/创意/矛盾）、Decision（确认/否决/变更历史）。项目任务 Agent 沿用现有模型，通过 ID 关联。具体字段、迁移、存储选型由 Codex 审查后提出，不强制新增数据库。
基础对象类型固定、具体分类动态演进；普通知识自动入库，重大/争议结论需确认；保留历史版本，以来源、时间、证据判断当前可信结论；AI 可研究推理创造，标注依据、来源和确认状态。区分事实、观点、推断。重复信息自动关联不删除，重大冲突提醒确认。

事件触发：新增/修改→提取索引关联与冲突检查；创建项目→推荐历史知识；研究→查证与纠偏；执行→依据真实状态识别风险；完成→回收成果、更新台账、提取经验；定期回顾→跨历史发现。按重要性动态调整回顾频率。连续提问继承当前记录/项目上下文，研究结果自动关联原记录。
AI 可自主整理、关联、公开资料研究、创意、风险判断、客观进度更新；付费、隐私、外部写入须授权；正式任务创建、计划变更、已确认结论变更、分派、验收、删除须人工确认。自动建议创建任务，用户确认后创建；手工任务和成果同样进入台账。AI 不承担 Agent 执行 runtime，复用连接/分派/回收机制。
提醒分紧急（立即）、重要（主动）、普通（相关页面）、低价值（不展示）。同类发现合并去重排序，无实质变化不重复提醒；否决后仅有新证据才重提。长期未推进结合重要性、期限、进度、依赖建议继续/延期/归档。
Token 效果优先，无预算上限；保留增量分析、指纹去重、缓存、按需检索、批量非紧急处理、适当模型分级。台账记录任务完成与证据，总结基于台账明确下一步，不额外展示无用总结。
