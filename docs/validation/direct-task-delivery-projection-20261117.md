# 普通任务交付后的状态投影

直接新建并执行的任务不必先建方向方案或交付槽。任务台帐已登记当前候选、源会话停在等待下一条消息且没有实际问题、权限请求、成果入库错误或未解决异常时，主任务行显示「待验收」。此判断复用已有交付就绪投影，不改源会话生命周期，不自动验收任务。

进展轨迹同时统计预先声明的交付槽与未分配槽位的当前台帐成果：前者使用「格」，后者使用「份直接交付」。只读当前版本的最新提交，排除失效、退回、待重新核对及未解决事项，不将历史附件重复计数，不自动补建方向或输出槽。有执行记录时，紧凑摘要不再写「尚无执行回执」。

实机只读调查确认：显示标题已摘要，但任务规范版本、执行绑定和提交规范版本一致；台帐为 in_review，已有最新成果且无当前源问题。根因是旧任务行直接使用源 waiting_reply，轨迹只统计输出槽。没有证据表明标题摘要破坏了执行版本。

定向校验：execution-progress.test.ts 覆盖无方案直接交付、待验收状态及计数、真实提问/授权、入库失败、执行失败、继续执行、失效版本、已认可成果与只读性；TypeScript 无错误；生产构建通过。原生安装复验由主任务执行。无真实数据库修改，无新模型调用。
