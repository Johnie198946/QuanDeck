# V0.17 项目删除、交接记忆与清洁交付

本规范取代早期将“删除项目”等同于归档、将审计流水作为默认项目记忆的行为。

## 项目删除与归档

- 项目列表、项目管理和设置中的“删除项目”均连接永久删除。由桌面后端展示一次原生确认，列明目标和范围；取消不产生变更。
- 确认后后端阻止目标项目的新派发，收尾其受管理的执行，验证源已停止，然后擦除该项目的本机数据。停止失败或受理不明时保留数据并解释原因，不让用户逐个归档会话。
- 删除在当前进程完成，刷新项目列表。其他项目、共享 Agent 配置和用户选择的工作目录原文件保留；删除不承诺撤销外部 Agent 的源会话或用户自己导出的副本。
- 应用管理的混合备份只清理目标项目，保留其他项目；恢复旧备份仍应用删除标记。迟到写入不得复活已删除项目。
- “归档项目”是独立可选项，保留内容、暂时收起项目。“已归档项目”中可以恢复或永久删除。恢复不自动派发任务。

## 给新会话的项目记忆

每个项目仅有一套业务记忆，由后端从该项目台帐确定性生成，不另建手工维护的真源。黑板仍是台帐的当前协作投影。

固定内容包含：项目背景和目标；已经确认的方向、约束及正式 Spec；任务的职责、验收条件和依赖；有效交付的总结和交接；当前阻塞、未完成事项和下一步。候选、已验收与正式发布分别表示，没有来源的信息明确留空。

执行事件、心跳、工具回执和用量明细不进入这份记忆，也不进入默认交接导出或新会话的业务上下文。摘要请求在发送边界使用白名单，旧队列与旧摘要中的流水不能回流。必要的运行恢复和来源校验记录留在内部存储，不能冒充业务总结。

新任务仍固定自己的完整要求、用户条件、已发布规范和必需前置正文/交接，保留身份与版本校验。简化记忆不得削弱这些强制输入，也不声称能证明模型理解或遵循内容。

用户可从项目管理读取、导出当前项目记忆。本机交接文件与 UI 使用同一代码投影。仅显式的本机诊断导出可以包含完整审计，不作为默认交接资料。

## 清洁源码与安装包

公开仓库只包含产品源码、合成测试、必要静态资源及不含真实业务数据的产品文档。排除用户数据库、日志、运行导出、备份、真实项目截图、个人路径、连接凭据及本地验收清单。

打包使用明确允许的运行文件，源码与打包结果均执行清洁门禁；发布器验证安装包对应的门禁证据。新安装启动为空项目、无个人 Agent 配置。检查失败不得发布。

私人测试证据、完整 Git 盘点和本机回滚信息保留在本地。仓库与安装包清理不自动重写已存在的 Git 历史或删除旧版本附件。

## 验收要求

合成项目覆盖直接删除、取消、可选归档与恢复、执行中收尾、停止失败、跨项目隔离、备份恢复与迟到写入；业务记忆追加大量心跳后正文与内容指纹保持不变；新请求与旧摘要队列均不携带流水。桌面实机检查删除入口、项目记忆和归档入口，并验证既有项目升级后保留。

交付前运行类型检查、领域及协议/存储回归、生产构建、清洁门禁和双平台原生安装检查。Release 的源码标签、安装包哈希和验证记录以对应发布页面为准。

本地集成通过全部领域回归、353 项 Node 测试、50 项发布器检查、类型检查和构建。隔离界面测试覆盖空库、项目记忆、四种窗口宽度、焦点返回及归档恢复；Mac 原生冒烟检查通过空白首次启动、实际持久化、默认记忆导出、恢复与删除保护。永久删除的执行停止、跨项目隔离、备份校验和迟到写入使用合成存储及真实协议测试进程验证，未删除用户项目。实机确认业务记忆可读、归档独立、删除只展示一次原生确认，取消后内容保留；升级前后原项目、不可变事实及共享配置均一致。

发布前复核补齐了删除后的连接缓存竞争：删除事务提交后，在任何异步等待和通知之前同步移除目标独占连接；另一项目的迟到连接检查不能重新保存旧连接。真实临时 SQLite 与桥接服务的并发测试同时覆盖成功及文件清理异常路径。双平台发布结果以 Release 验证记录为准。
