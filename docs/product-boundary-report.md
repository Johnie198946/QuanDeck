# 产品边界简报

QuanDeck 应帮助用户想清楚目标、安排下一步、看见进展、获得成果并积累经验。Agent 是可替换的执行者。

| 问题 | 结论与处理 |
| --- | --- |
| 越来越像 runtime | 判断成立。保留任务依赖、交接、验收；会话恢复、工具循环和原生权限归源 Agent，连接层只做必要适配。 |
| 任务流程过重 | 普通任务直接创建；复杂事情才讨论方向。只拆到动作明确或可独立交付，不强制层层拆分。 |
| 进展不清楚 | 展示已做成的部分、当前动作、阻塞、下一步及证据；没有依据不编百分比。 |
| 碎片与经验混杂 | 碎片先收集，关联到项目；有来源的结论进入记忆；复盘经验注明情境和限制。 |
| 是否推 GitHub | 本轮记忆功能有产品代码变更，通过验证后应推送清洁源码并发布；真实项目、测试输出和本机记录不上传。 |

项目记忆采用[独立设计规范](project-memory-design.md)：一项目一套记忆，按任务取用，代码维护来源和有效状态，长资料按需读。

本轮只实施项目记忆。对工作台和 runtime 的以上判断是评估建议，本轮不重构它们。
