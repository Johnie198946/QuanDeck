# 从笔记查询工作台、核实资料、交办任务

选中文字后有两个入口。气泡用于提问，纸飞机用于交办。选到整句问题时，点气泡后可直接发送。回答保存在该选段下方，派发结果沿任务的来源回执返回笔记。

## 提问时能查什么

| 想知道的事 | 用什么记录回答 | 点击结果去哪里 |
| --- | --- | --- |
| 哪些事项还没划去 | 笔记中的列表项和待办行，逐行核对删除线 | 命中笔记的原句 |
| 之前有什么灵感或关联 | 灵感画布、连线和知识图谱 | 卡片或关系详情 |
| 项目里还在做什么 | 项目和任务的状态、负责人 | 项目或任务 |
| 有什么需要我介入 | 执行记录、待处理提醒 | 对应任务或提醒 |
| 今天要做什么 | 首页日程、完成状态和进展 | 对应日期的日程 |
| 我把这件事记在哪 | 工作台现有的搜索索引 | 笔记、任务或搜索结果 |

1. 能直接识别的问题由应用先查。比如查删除线，应用从所有笔记逐行计数，忽略代码块、整行已划去的项和提问本身。部分划去只取剩余文字。已勾选的待办和已画删除线是两种独立标记。这项统计的口径会写在结果卡上。
2. 问法较宽时，Agent 可用关键词指定一个或多个模块，应用执行一次补查。用户只问翻译时，直接把选段交给 Agent。Agent 能看到命中记录的简短依据，所有可跳转的位置及完整计数由应用保存。
3. 结果默认显示总数、笔记名和事项短标题。长句优先提炼动作及对象，点一条就回到原文。更多条目按需展开。这些数字是提问时的记录，重新提问会读取最新状态。

## 资料里有网址时

读取选中的笔记、灵感或补充背景中实际引用的公开网址。回答里分别列出已读来源、可核对的摘录和未取得的信息。地图的酒店名单、报价、空房以及不同年份的预测需要相应页面内容支撑。用户可补一张截图、贴出表格或补充文字后再问。

## 交给谁做

点击纸飞机可选择已有项目或新建项目，确认后建立任务并派给选中的 Agent。已有项目沿用自己的工作目录。新项目、以及尚无目录的项目，自动获得独立文件夹；需要处理一份已有工程时，可主动展开「任务文件夹」选择。重复提交同一次发送会打开同一项任务，结果保留来源笔记的位置。
