# QuanDeck V0.11：从目标到自动交付

更新：2026-11-17。发布和验收状态以 Release 回执及 completion manifest 为准。

## 目标与入口

项目工作台、总览项目节点和任务行直接提供“方向方案”。项目方案不再借用一个假的业务任务；内部讨论记录只承载源会话，不进入业务任务数量、目标图或交付地图。方向页同时展示目标、章节大纲、正文、执行顺序和交付清单。旧方案只有目标时明确提示尚未形成内容，不拿模板文字冒充已经制定的方案。

普通“新任务”继续直接创建任务。只有用户选择讨论方向，才进入讨论；方案讨论只确定方向和执行逻辑。用户可在讨论中比较真实照片、Google 路线和选项卡片，对具体卡片表达偏好。卡片偏好不等同于整份方案授权。

## 一次确认后的自动流程

主动作是“确认方向并自动执行”。确认绑定当前方案版本，然后开启该版本的自动执行。已确认的方案直接显示“开始自动执行”，不重复确认。项目尚无任务结构时，自动先请求拆解；返回后在同一已确认方向下建立任务、嵌套子任务及依赖。任务可以各自产生多个交付件。

已确认的任务或子任务方向没有拆分草稿、且当前范围没有有效子任务时，开启自动执行直接派发该任务。后端把现有任务键及规范版本绑定到自动执行计划，子任务必须保留 `workItemId`，不扩大为整项执行，不新增业务任务或成果槽，不覆盖项目成果地图。只有确认方向不会派发；人工负责人、依赖未就绪、旧会话受理不明和未确认停止仍由原有台帐门禁阻止执行。候选提交使用原项目成果槽，没有额外交付槽的直接执行按实际提交完成状态收束。后续需要拆分时保留原任务作为父层，不能将它当成移除节点归档。

独立叶任务按依赖就绪派发；父层等待子任务成果到齐，再执行本层汇总，避免从头重做所有子任务。完成一个节点后，其真实成果可供当前已授权计划中的后继任务使用，后继自动推进。用户无需逐项点击派发或汇总。

自动执行授权不是人工验收。可用候选仍明确标记“候选”；被退回、要求变更、来源失效的结果不能继续作为有效输入。权限请求、失败、待回复和受理不明在对应节点停住并给出原因。外部付款、订购等操作仍遵循源 Agent 的权限边界。

每次派发先记录持久化意图，再记录受理回执。重启恢复从回执继续，不能重新发送受理不明的任务；重复点击与重复回传不能生成第二份任务或派发。方案或任务规范版本变化使旧自动授权失效，必须基于新版本明确启动。

## 目标拆解图

总览使用目标层级图：项目目标 → 主任务 → 子任务，辅以依赖提示和真实状态。鱼骨图适合分析原因，无法清楚表达执行依赖和产出归属，因此不用于任务编排。

项目标签显示完整目标路径，任务标签聚焦任务。展开层级与进入方向分开；搜索保留命中节点的祖先。节点可直接进入方向或对应成果地图，不经“查看任务与执行”过渡页。任务工作台直接显示子任务拆解路径，无须先展开一大段历史记录。

## 交付地图与自动组装

拆解时同时声明交付槽及其负责任务，例如路线、酒店、日程、预算。项目成果页按交付大纲排列，任务与子任务成果页使用同一数据按范围过滤。未提交的槽保持空位；运行中、阻塞、候选、认可、待修改、已过期分别说明。不是每个槽只要有一份结果就标绿。

任务只有一个交付槽时可以关联该任务的真实提交；同一任务负责多个槽时，结果必须显式声明对应槽，不能把一段文本复制到所有格子。跨项目、其他任务、旧规范的内容不能补到当前空位。自动组装直接读取台帐中最新有效成果引用，不复制出另一套内容或要求手动点“汇总”。

用户点击槽即可阅读图文正文、图片、地图、文件和来源；宽屏显示目录与阅读区域，窄屏保持顺序回流，放大使用回弹动效并尊重减少动态效果设置。历史已保存成果仍可读取，不因新版地图没有对应声明而丢失。

结果内容仅集中在项目成果地图及任务/子任务成果页。总览和执行侧栏不再散列“最近成果”正文；任务行只保留状态、方向与成果入口。讨论中的视觉证据属于方案内容，不当作已交付成果。

## 唯一真源

方向版本、任务层级、依赖、交付槽绑定、自动执行授权和运行回执写入台帐。成果正文仍由原始提交与产物记录持有。黑板、目标图、成果地图、进度和方向页面全部从相同事实派生，允许重建；界面不能靠本地百分比或聊天摘要改变任务完成状态。

## 验收范围

- 项目方向不新增业务任务；项目、任务、子任务方向入口可直接访问。
- 同版确认幂等，旧版本、跨项目操作拒绝；一次确认可自动拆解和执行。
- 嵌套任务依赖调度、失败/权限等待、重启恢复与重复派发保护。
- 叶子方向无拆分时直接执行本任务；精确子任务范围、已有项目成果槽不变、旧受理不明仍暂停。
- 多槽精确映射、部分成果、空位、退回、过期和子任务范围隔离。
- 原图文讨论、时间轮盘、附件粘贴/上传和一行补充入口回归。
- 320／768／1024／1440／1920 宽度、键盘进入/退出、放大和减少动态效果。
- Apple Silicon Mac 与 Windows x64 安装、启动、卸载及构建提交核对。
