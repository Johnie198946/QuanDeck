# 0.3.0 · 任务成果地图

成果详情保留任务、方法和执行结果的关联，默认将长列表替换为可以逐层进入的任务地图。

- 顶部环图统计当前层的直属子任务，进入分支后切换为该分支的进度。
- 地图连线表示父子关系；阶段来自任务本身的数据。点击节点更新方法与成果，进入分支查看下一层，面包屑返回上层。
- Token 条形图统计各分支独立用量，不把包含子任务的主会话用量重复累计。未知用量保持待同步。
- 成果足迹展示有实际完成回报的时间点；运行时间按当天真实执行区间取并集。
- 窄屏下任务地图、方法、结果切换显示；所有内容占满当前页面宽度。
- 地图仍提供列表模式，便于逐项浏览。

桌面版提供 macOS DMG 与 Windows NSIS 安装程序。GitHub Actions 在对应操作系统验证安装、启动和移除，并保留验证记录。
