# 页面与交互规范
文字规则优先于历史原型；原型仅供视觉参考。白底/浅灰、黑白灰文字、主题蓝仅用于重要操作；标题左对齐，靠字号和粗细区分层级；禁止 emoji、发光、玻璃、渐变、多重阴影、装饰描边、无意义说明。

## 首页
最重要三件事优先，领导交办优先。点击主模块原地展开填满工作区，其余模块缩为右侧纵向按钮。重大关联及时提醒，不平铺所有统计。
## 帮你记
备忘录式自由记录文本、图、链接、语音转写、附件；一键归档，保留来源。工具栏简化为撤销、字体、格式、插入，分享放三点。选中文本→弹窗提问→AI 扩写追加在原文后，引用框细线连接锚点，可取消；多次选择独立分组、连线不交叉。无常驻聊天框。新增资料自动进入统一知识库。
## 帮你想
默认灵感列表，点击后左侧原文、右侧图谱。节点为灵感及具体对象/要点，边为关联、冲突、补充、同源；悬停节点/边展示对象和依据，点击跳转原文。跨项目关联。不设问AI、新创意、开始做入口。
## 帮你管
项目列表与现有项目工作区复用。项目页签：总览、任务、甘特图、成果、记忆。总览展示目标、进度、期限、负责人、风险、完整任务计划和里程碑。
创建项目仅增加一个页面：创建（名称、目标、可选附件/期限）→理解需求（AI 摘要、相关知识、必要问题、开始研究）→校准任务（AI 拆解、人工逐项确认修改）。前两步完成后折叠，第三步展开；支持拖拽排序/层级、合并拆分删除、撤销。校准在当前页附件/详情中完成，不另开页面。确认后进入现有总览，继承数据，不编造进度。
任务页：左任务树，右详情；优先级 P0–P5，支持折叠拖拽。标题行开始研究在三点左侧；负责人、日期、优先级；四区为研究信息、研究结论、验收标准、交付物。人工填写或 AI 原地研究；结论待确认，不覆盖已确认内容；简单任务可跳过研究。无完成研究按钮、研究中徽标、研究/执行/成果/讨论/历史额外页签。讨论采用选词内联方式；有证据的主动质疑可接受或保留原判断。
甘特图：复用左侧任务树，不再重复任务列；行对齐，同步滚动折叠；上下拖排序、左右拖时间、调整长度，依赖影响提示、撤销；日周月在负责人日期行，今天线，单项目及跨项目。
分派：拖动任务时底部 Agent Dock 自动升起，真实 logo、状态、队列、自定义、添加及自己；悬停高亮，松手弹确认框（任务、可多选 Agent、折叠的目标/研究/结论/验收/交付物），确认后消失。无常驻 Dock 或中转区。多 Agent 独立执行，用户选择或合并结果，不自动合并。
成果：按任务组织，直接阅读编辑文本、图片、PPT/PDF、代码差异、混合成果、行动凭证；版本、验收、退回、多 Agent 对比按需出现。
记忆：仅按时间记录项目过程，点击看来源、任务、原因；无分类和 AI 动态总结展示。底层台账和总结仍保留。
## 帮你盯
需要你处理（阻塞、决策、逾期、待验收）优先；正在执行（人/Agent，真实证据）；等待执行（队列）。点击 Agent logo 展开队列，点击进度看依据，异常看原因与建议，验收跳成果；人工任务可更新/上传，队列可排序。立即提醒、延期/完成/拒绝并记录。无重复任务树、终端、常驻日志。历史原型多出的帮你做必须删除。
## 帮你找
初始主区只有搜索框，无分类、历史推荐。搜索后保留搜索框，展示相关结果标题、摘要、来源、时间、原文跳转；支持自然语言和跨项目检索。全局搜索若保留必须共用能力。原型中的相似度百分比不是必需，不可伪造。
## 设置
复用现有连接机制，四类：个人资料（名称、头像）、Agent 管理（添加、配置、测试、移除、默认、自定义）、提醒（重要事项、异常、长期无进展）、数据管理（存储、备份、恢复、导出）。删除独立显示设置，不加预算配置。中间分类、右侧当前设置；高级配置按需展开。
