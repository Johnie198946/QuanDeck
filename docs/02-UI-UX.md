# 页面与交互规范
文字规则优先于历史原型；原型仅供视觉参考。白底/浅灰、黑白灰文字、主题蓝仅用于重要操作；标题左对齐，靠字号和粗细区分层级；禁止 emoji、发光、玻璃、渐变、多重阴影、装饰描边、无意义说明。

## 首页

日程是首页面积最大的区域。每行保留时间、事项和来源。有进展时在标题下显示最新一条，展开才显示带时间的记录和输入框。笔记待办和项目日程都可记进展，返回首页仍能看到。

提醒以设备本地时间显示，提前一小时和到点各提醒一次。之后每天在下一次 08:00、18:00 提醒未完成的事项。跨到第二天按原钟点顺延，原始日期供追溯。跨过一个本地日期显示橙色，三天起显示红色，同时写明天数。完成后停止提醒。桌面通知遵循系统和应用设置，退出后重新打开只补最近一次。

「项目进展」默认显示四列任务看板，沿用列表和甘特图查看排期。个人待办、本人负责和交给 AI 的任务都能从这里找到。点任务能看到原想法、最近进展、返回的成果及子任务。已关联的笔记待办并入对应的项目卡，单独的灵感保留在笔记本。现在需要决定或验收的事仍有独立入口。

| 谁来做 | 首页的分工 |
| --- | --- |
| 系统 | 按来源编号归集任务和成果，按真实执行状态分列，按时提醒。用最新记录和成果标题做摘要，支持按项目、经手人和原话查找。 |
| AI | 接到任务后研究或制作成果，项目内保存返回的文件、结论和出处，回到首页即可查看。 |
| 我 | 记录系统看不到的进展，选择是否把灵感变成任务，遇到分歧作决定并核对交付。 |

## 帮你记
标题和工具栏固定在顶部。圆点列表、编号列表各用一个标准图标。选中带删除线的文字，再点删除线即可取消。「插入」提供表格、图片、附件、链接、分隔线和转写。

截图可直接粘在光标处。编辑和全屏阅读时，图片与文件只在正文插入处展示。分隔线下方可继续输入，保存重开后也可接着写。拖入 Word、Excel、PPT 或 PDF 后，预览卡就在正文里，插入的链接也可就地查看。停止编辑 30 秒自动保存到本机，切换笔记或页面时立即保存。Mac 的分享图标打开系统分享菜单。旁边的全屏图标可放大当前草稿，上下滚动阅读；按 Esc 或点关闭返回原来的编辑位置。改动记录显示时间、增删内容和修改前后的文字。选词提问默认只把问题和所选文字发给已连接的 Agent，收到原文就显示。等回答时可以继续写或切换笔记；收到的回答保留提问时的引文和来源。保存后的笔记自动进入统一知识库。

打字、选词或移动鼠标时，行尾按钮收起。鼠标在一行停稳，或光标停在行尾时，文字末尾留两个汉字的间距，再显示两个按钮。可点「to do」加入日程，或点纸飞机把这行发到「帮你管」的指定项目。待办缩进两个汉字，行尾显示时间，指向时间可查看月日。点击时间，待办菜单会保持打开，可以移过去点「取消待办」。原句保留，该项从首页日程移除。时间按本机时区识别，未指定时默认在创建后八小时到期。

## 帮你想
「知识图谱」默认显示整本笔记。左侧选灵感，中间读内容，右侧看图。选一条线就能看到两端的笔记、关系名称、关联原因和原文依据。暂时独立的笔记也要能找到。图谱区分本地发现与 Agent 分析，保留回到原文、忽略及恢复的入口。

「灵感逻辑」用于自己编排做事的方法。插入已有笔记，从第一张卡片的输出点连到下一张的输入点，给线起名，在右侧解释先后关系。保存笔记引用、位置和有向连线。移动或移除卡片只改变画布。详见[帮你想的连线与原文依据](06-INSPIRATION.md)。

## 帮你管
项目列表与现有项目工作区复用。项目页签：总览、任务、甘特图、成果、记忆。总览展示目标、进度、期限、负责人、风险、完整任务计划和里程碑。
创建项目仅增加一个页面：创建（名称、目标、可选附件/期限）→理解需求（AI 摘要、相关知识、必要问题、开始研究）→校准任务（AI 拆解、人工逐项确认修改）。前两步完成后折叠，第三步展开；支持拖拽排序/层级、合并拆分删除、撤销。校准在当前页附件/详情中完成，不另开页面。确认后进入现有总览，继承数据，不编造进度。
任务页：左任务树，右详情；优先级 P0–P5，支持折叠拖拽。标题行开始研究在三点左侧；负责人、日期、优先级；四区为研究信息、研究结论、验收标准、交付物。人工填写或 AI 原地研究；结论待确认，不覆盖已确认内容；简单任务可跳过研究。无完成研究按钮、研究中徽标、研究/执行/成果/讨论/历史额外页签。讨论采用选词内联方式；有证据的主动质疑可接受或保留原判断。
甘特图：复用左侧任务树，不再重复任务列；行对齐，同步滚动折叠；上下拖排序、左右拖时间、调整长度，依赖影响提示、撤销；日周月在负责人日期行，今天线，单项目及跨项目。
分派：拖动任务时底部 Agent Dock 自动升起，真实 logo、状态、队列、自定义、添加及自己；悬停高亮，松手弹确认框（任务、可多选 Agent、折叠的目标/研究/结论/验收/交付物），确认后消失。无常驻 Dock 或中转区。多 Agent 独立执行，用户选择或合并结果，不自动合并。
成果：按任务组织，直接阅读编辑文本、图片、PPT/PDF、代码差异、混合成果、行动凭证；版本、验收、退回、多 Agent 对比按需出现。
记忆：仅按时间记录项目过程，点击看来源、任务、原因；无分类和 AI 动态总结展示。底层台账和总结仍保留。
## 帮你盯
需要你处理（阻塞、决策、逾期、待验收）优先；正在执行（人/Agent，真实证据）；等待执行（队列）。点击 Agent logo 展开队列，点击进度看依据，异常看原因与建议，验收跳成果；人工任务可更新/上传，队列可排序。立即提醒、延期/完成/拒绝并记录。无重复任务树、终端、常驻日志。历史原型多出的帮你做必须删除。
## 帮你找
初始主区只有搜索框，无分类、历史推荐。搜索后保留搜索框，展示相关结果标题、摘要、来源、时间、原文跳转；支持自然语言和跨项目检索。全局搜索若保留必须共用能力。原型中的相似度百分比不是必需，不可伪造。
## 设置
复用现有连接机制，四类：个人资料（名称、头像）、Agent 管理（添加、配置、测试、移除、默认、自定义）、提醒（重要事项、异常、长期无进展）、数据管理（存储、备份、恢复、导出）。删除独立显示设置，不加预算配置。中间分类、右侧当前设置；高级配置按需展开。
